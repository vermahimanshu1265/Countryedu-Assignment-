CountryEdu – Intelligent Recruitment Workflow Engine

CountryEdu is a recruitment workflow web application designed to streamline candidate applications, eligibility evaluation, recruiter worklists, and audit tracking.


Live Demo

https://hvsj.oneapp.dev/


Key Features


Configurable eligibility rules

Target graduation year filtering

Minimum CGPA requirement

Branch-based eligibility

Minimum experience requirement

Candidate application form

Unique email validation

Recruitment pipeline and role-based worklist

Recruiter view switching

System audit logs

Dynamic rule evaluation without code deployment


Application Flow


Recruiter configures eligibility rules.

Candidate submits their application.

The system evaluates the candidate against the configured rules.

Eligible candidates move through the recruitment workflow.

Recruiters manage candidates from the worklist.

Important system actions are recorded in audit logs.
